# Old Windows installer (removed)

The Cloudflare / Twilio / Git installer that used to live here was replaced.

Use the USB kit at the repo root instead:

- `SETUP.bat` — install MongoDB + Node, copy the app to `C:\Electroshack\app`, start it
- `START.bat` — open the already-installed app
- `BACKUP.bat` / `RESTORE.bat` — dump/restore MongoDB onto `backups\` on the USB
- `usb/README.txt` — local login credentials

No Cloudflare Tunnel, Twilio, Git, or Atlas account is required to run the store PC.
